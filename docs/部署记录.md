## 三、目录与进程

```text
/opt/online-shop-src/     Gitee 仓库克隆，用于构建
/opt/online-shop/         运行目录
/opt/online-shop/online-shop.jar
/opt/online-shop/data/mail/
/etc/online-shop.env      数据库和 SMTP 环境变量（权限 600）
/etc/systemd/system/online-shop.service
/etc/nginx/sites-available/online-shop
```

服务：

- `online-shop.service`：Spring Boot 应用，监听 `127.0.0.1:8081`
- `mysql.service`：MySQL 8，仅监听本机 3306
- `nginx.service`：监听 8080，反向代理到 8081

三个服务均已 `systemctl enable`，应用配置 `Restart=always`。

## 四、反向代理要点

Nginx 使用：

```nginx
proxy_set_header Host $http_host;
proxy_set_header X-Forwarded-Host $http_host;
proxy_set_header X-Forwarded-Port 8080;
proxy_set_header X-Forwarded-Proto $scheme;
```

应用环境变量包含：

```properties
SERVER_FORWARD_HEADERS_STRATEGY=framework
```

否则登录/注册跳转会丢失 8080 端口，跳到 80 端口后返回 502。

## 八、三个月可用性

- 服务器已购买一年，有效期至 2027 年 10 月（2026 年 10 月 30 日确认）；
- 该期限可覆盖本课程期末提交报告后的三个月；仍须确保从提交报告之日起三个月内，网站在校园网内可正常访问；
- 每月检查 `systemctl status online-shop mysql nginx`；
- 建议每周备份数据库：

```bash
mysqldump -u online_shop -p online_shop > online_shop_$(date +%F).sql
```

- 不要删除 `/etc/online-shop.env` 或 `/opt/online-shop/`。
