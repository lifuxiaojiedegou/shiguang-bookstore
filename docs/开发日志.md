# 开发日志

记录时间：2026-10-17 至 2026-10-21

说明：本日志补充 Git 提交历史，记录每个模块的目标、关键提示、验证结果和踩过的坑。提交历史按本日志对应的日期重建，最终代码以 `main` 分支为准。

## 2026-10-17：工程骨架与第一个页面

- 目标：搭好 Spring Boot 工程，能启动并返回第一个页面。
- 完成：生成 Spring Boot 4.1.1 工程，配置 Thymeleaf、Spring JDBC、Security、Mail、MySQL 驱动；创建本地数据库和专用账号。
- 关键提示：先确认 JDK 和 MySQL 环境，再生成最小工程；第一个 Controller 只返回一段 HTML。
- 验证：`./mvnw spring-boot:run` 启动成功，浏览器访问 `/hello` 返回 200。
- 问题：
  - MySQL 未启动导致 `Communications link failure`，后来通过启动脚本解决。
  - 删除 `produces` 后页面显示原始 HTML，理解了 `Content-Type` 的作用。

## 2026-10-18：模板、商品表与商品列表

- 目标：把 HTML 搬到 Thymeleaf，建立商品表并显示商品列表。
- 完成：`index.html`、`hello.html`、`product` 表、`data.sql` 幂等演示数据、商品列表、搜索和分类筛选。
- 关键提示：数据库脚本要可重复执行；金额用整数“分”；搜索参数全部用 `?` 绑定。
- 验证：5 件商品正常显示；搜索 `Java`、分类 `教材`、组合无结果均符合预期。
- 问题：
  - `data.sql` 中 `prduct` 拼写错误，启动时报 SQL 错误。
  - `findById` 的字符串拼接漏了空格，出现 `activeFROM`。

## 2026-10-19：注册、登录与权限

- 目标：完成账号体系和角色权限。
- 完成：`shop_user` 表、BCrypt 密码、注册页、登录页、Spring Security、CSRF、`CUSTOMER` / `ADMIN` 角色。
- 关键提示：密码必须加盐哈希；登录后更换 Session；退出用 POST；管理员路径在服务端鉴权。
- 验证：注册成功、重复邮箱、密码不一致、错误密码、未登录跳转、顾客访问后台 403。
- 问题：
  - `@RequestParam` 的 `defaultValue` 拼写错误。
  - `OrderService` 缺少 `@Service`（后续模块）。
  - 修改数据库角色后没有重新登录，Session 中仍是旧权限，导致 403。

## 2026-10-20：购物车、下单与订单状态

- 目标：完成从购物车到订单的完整交易链路。
- 完成：`cart_item`、购物车增删改、结算页、一次性令牌、`orders` / `order_item`、事务扣库存、订单列表、付款、取消恢复库存、管理员发货、确认收货。
- 关键提示：下单必须放在事务里；扣库存用 `stock >= 数量` 条件更新；订单明细保存快照；取消和发货都用带状态条件的 UPDATE。
- 验证：下单后库存减少、购物车清空；库存不足时事务回滚；取消恢复库存；付款、发货、确认收货状态正确。
- 问题：
  - `findById` 的 SQL 拼接错误。
  - `OrderService` 忘记加 `@Service`，应用启动失败。
  - `OrderView` 字段写成 `orderm`，模板取 `order` 报错。
  - 后台模板把邮件表单放进发货表单，且 `<p>` 内嵌 `<form>`，导致模板解析异常。
