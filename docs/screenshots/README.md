# 截图清单

截图统一放在本目录（`docs/screenshots/`），文件名按下面的编号命名，方便报告引用。

## 拍摄前准备

1. 启动 MySQL 和应用，确认 `http://localhost:8080` 可访问。
2. 准备两个演示账号，避免使用个人真实信息：
   - 顾客：例如 `demo@example.com`
   - 管理员：例如 `admin@example.com`，并在数据库中把角色改为 `ADMIN`
3. 准备一组演示订单，覆盖：待付款、已付款、已发货、已完成、已取消。
4. 浏览器使用 1440 或 1920 宽度、100% 缩放，**保留地址栏**。
5. 收货信息使用虚构的姓名、电话和地址。
6. 截图里不要出现：
   - 数据库密码
   - SMTP 授权码
   - 真实手机号、真实住址
   - 个人常用邮箱（建议用演示邮箱）

## 截图后的处理

- 检查每张图是否包含密码、授权码、真实个人信息；
- 报告里按编号引用，例如“如图 6-1（`06-checkout.png`）”；
- 如果仓库是公开的，只提交脱敏后的截图；
- 不建议用修图软件伪造状态；所有截图应来自实际运行。

## 建议的截图顺序

1. 先注册演示顾客，登录后截首页、搜索、购物车；
2. 下单、付款、取消各截一张；
3. 用管理员发货，截后台和邮件状态；
4. 顾客确认收货，补齐订单状态；
5. 最后截数据库和启动日志；
6. 部署完成后再补 23–25。
